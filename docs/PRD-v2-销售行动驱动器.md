# WeFlow 销售行动驱动器 — PRD v2

> 截至 2026-07-28，基于 PRD v0.2 的全面重定位。
> 权威需求来源：本文件。技术操作手册：`MAINTENANCE.md`。

## 一、产品重新定位

**一句话**：从"微信聊天记录查看器 + AI 分析附件"变为"每天打开就知道该干什么"的零操作销售行动驱动器。

**核心原则**：
- 用户**不录入、不标记、不操作**——所有数据从微信聊天自动提取
- 用户只做两件事：**看清单** 和 **打勾**
- 所有功能必须喂进"今日行动 → 白天辅助 → 周期复盘"循环，不喂的砍掉

**用户画像**：
- 叉车/仓储设备个体销售，月新增 200-500 微信联系人
- 两极分化：小单（配件/小电车）几天成交，大单（大吨位/仓储方案）跟 1-3 个月
- 试过 CRM 没坚持——重工具不行，必须零操作
- 最痛：报了价没回、聊到一半断了、该催的忘了催

## 二、核心循环

```
早上 8:30  → 打开 WeFlow → "今日行动"屏（10-15 件事，按优先级排）
           → 每件事：谁 / 为什么 / 建议说什么 / 一键完成
白天       → 在微信聊天时，WeFlow 聊天页显示客户上下文卡片（阶段/上次聊什么/建议）
周末       → 自动推送"本周复盘"：谁热了/谁冷了/谁该放弃/管道健康度
```

## 三、功能模块与优先级

### P0：今日行动引擎（第 1 周）

#### 3.1 自动阶段追踪

| 阶段 | 判定规则 |
|------|------|
| `new` | 首次对话 ≤3 天，尚未实质沟通 |
| `contacted` | 有实质问答（问过产品/价格/参数） |
| `quoted` | 我方发过报价/方案 |
| `negotiating` | 讨论付款方式/交期/定制/比价 |
| `won` | 确认下单/付款/发货 |
| `lost` | 明确拒绝 / 超 60 天无互动且最后意向为负 |
| `dormant` | 超 30 天无互动（非 lost） |

- 触发：WCDB DB monitor 检测新消息 → 异步轻量 AI 分类（≤500 token）
- 存储：`customer_profile.stage` + `intent_tag_log`
- 冷启动：首次启动批量扫描最近 90 天有消息的会话

#### 3.2 触发规则引擎

| 规则 | 条件 | 生成任务 | 优先级 |
|------|------|----------|--------|
| R1 | stage=quoted 且 ≥3 天无互动 | 报价跟进 | 高 |
| R2 | stage=negotiating 且 ≥2 天无互动 | 谈判跟进 | 高 |
| R3 | stage=new 且 对方发消息我方未回 ≥1 天 | 新客响应 | 紧急 |
| R4 | stage=contacted 且 ≥7 天无互动 | 激活沉默 | 中 |
| R5 | stage=dormant 且 历史有正向意向 | 唤醒 | 低 |
| R6 | 30 天内第 3 次触发 R4/R5 | 考虑放弃 | 信息 |

- 频率：每天 8:00 全量 + 新消息增量
- 去重：同客户同规则 24h 内不重复
- 每日上限 15 条

#### 3.3 今日行动页面

- 路由 `/` `/home`（替换 SalesDashboardPage）
- 单列卡片流：头像+名字+阶段标签 / 触发原因 / AI 建议话术（可复制）/ 完成+跳过按钮
- 排序：紧急>高>中>低>信息；同级按沉默天数降序
- 顶部 4 数字卡（缩小为一行）

### P1：周期复盘（第 2 周）

- 每周日 20:00 自动生成
- AI 生成行动建议（非纯统计）
- 知识库批量导入 + 产品数据填充
- 行动卡片话术引用知识库

### P2：白天辅助（第 3 周）

- 聊天页右侧"销售上下文"折叠区
- 阶段/关键消息摘要/报价记录/AI 建议

### P3：UI 瘦身（与 P0 并行）

侧边栏保留：今日行动、聊天、客户、知识库、复盘、通讯录、设置
隐藏：朋友圈、年报、双人报告、足迹、群分析、资源浏览、导出、公众号、灵感信箱
删除：cloudControlService、salesAlertService

## 四、数据模型变更

不新建表。`customer_profile` 增加 `last_stage_change_at INTEGER`（ALTER TABLE 迁移）。

## 五、开发顺序

| 周 | 任务 | 验收 |
|---|---|---|
| 1 | stageClassifier + actionEngine + TodayActionPage + 侧边栏裁剪 + 删死代码 | 首页显示行动卡片；新消息后阶段自动更新；完成/跳过可用 |
| 2 | weekly review + 知识库导入 + 产品数据 | 周日自动复盘；知识库≥30条；话术引用知识库 |
| 3 | 聊天页上下文卡片 + 打包 | 聊天时右侧显示阶段/建议；Win/Mac 打包验证 |

## 六、不做项（大后期优化）

- CRM 双向同步 / 多账号协同 / 向量数据库
- 自动发消息（WeFlow 只读）
- 触发规则配置 UI（v1 硬编码）
- 实时辅助回复填入输入框（只做一键复制）

## 七、假设

- AI 分类用 DeepSeek，prompt ≤500 token，响应 ≤100 token
- 月 500 人 × 每天 1 次 ≈ 500 次调用/天，成本 ¥1-2/天
- 规则阈值为初始值，后续微调
- 冷启动 90 天 × 50 条/批 × 串行，约 10-20 分钟
