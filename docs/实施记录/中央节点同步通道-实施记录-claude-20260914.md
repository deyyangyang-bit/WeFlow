## 3. 安全边界（逐条对照任务要求）

| 要求 | 落实方式 |
|---|---|
| 所有 SQL 参数化 | 投影写入只产 `$n` 占位符（`projections.ts`），由 `migration-test` E1/E2 静态断言「不存在手拼 payload 的 SQL」 |
| 令牌只存哈希 | 设备令牌与邀请码均 `secretHash`（sha256）落库，明文只在响应体出现一次；`app-test` B2/B3 断言哈希一致且明文不在任何 store 行里 |
| 日志不输出 token / 邀请码 / AI Key / 敏感信息 | Fastify logger `redact` 排除 `authorization` 与 `idempotency-key`；错误处理只记 `message/stack/code`（不整体落 pg 异常，其 `parameters` 可能带业务值）；`migration-test` E3/E4 静态断言 |
| 配置的日志级别真正生效 | `config.logLevel` 真实传入 Fastify logger（`app.ts` 构造处） |
| 不扫聊天表上行 | `centralProjection.ts` 只读 customer / customer_identity / assignment / account / opportunity / quotation+contract / audit_event / customer_judgment / knowledge_base；无任何聊天或消息表读取 |
| 不传聊天正文 / session_id / WCDB 路径 | `findForbiddenCentralField` 递归拦截 5 类键；judgment 的 session_id 先映射 customer_id，映射不到**跳过该行** |
| 身份值脱敏 | 只上行 `identityHash`（sha256(`type:value`)）+ `identityMasked`（如 `138****11`），原文不出本机 |
| 不可回退的旧路径 / 双写 | 未恢复任何禁用路径；下行只经既有状态机，未新开第二套写入通道 |
