侧边栏收编 + 重要提醒瘦身 · UI 设计稿

原则不变：身份只决定看什么，不决定能干什么（宪法 §1.12 不破）。销售侧栏只摆日常 6 项，其余收进「更多」；主管/你照旧全量。纯展示层，路由全部保留可直接访问。

屏 2

重要提醒页 · 打开就是一列告警

现状 599 行里混着「筛选条件」「请求日志」等调试区块。改法：默认视图 = 纯告警列表（每条 = 类型 pill + 客户 + 一句话 + 原话证据 + 时间）；筛选收成一行小字；「请求日志」整区折叠默认收起（排查问题时展开）。
