实现规格（开发必读，与本稿同效力）

项硬约束
视觉 token唯一来源 = src/styles/main.scss「前进视觉 tokens」（--color-* 族）；禁止硬编码品牌色/字面 hex（DESIGN-SPEC-MINI 红线 2/3）；品牌色走 --primary alias 继承，默认 Apple 蓝 #0071E3
字号层级统计主数字 26px/700 tabular-nums · 页标题 16px/700 · 正文 13-14px · 辅助 12px · 元信息 11px；数字一律 tabular-nums
圆角/间距/布局圆角：卡 16 / 控件 10 / 小件 8；页面 padding 24、卡间距 14；页面限宽 1280 居中；表格数字列右对齐（SearchTable 惯例）
控件惯例分段控件 = 灰底 + 选中浮起 + accent 文字；pill 徽章五语义（蓝=信息 / 绿=正常 / 琥珀=临近或待办 / 红=超时或异常 / 灰=中性）；卡片弱底无边框、hover 才浮起描边；弹层 = overlay + blur + shadow-pop
双模式所有新组件必须 light / dark 双验（DESIGN-SPEC-MINI 红线 4）
数据口径一律以 docs/DATA-CONSTITUTION.md 为准：assignment 状态 ∈ {assigned, claimed, recycled, transferred}；倒计时读两段 SLA 计时字段；留痕读 ownership_history；审计读 audit_event；前端不改口径、不另造状态值
路由注册新页面三处必改：App.tsx 路由 + Sidebar.tsx NAV_GROUPS + RouteGuard.tsx（AGENTS.md 技术约定）
验收方式实现后无头浏览器逐屏截图（1440 宽），与本稿并排比对：布局结构 / 文案 / 状态徽标不一致即打回；「差不多」不验收
