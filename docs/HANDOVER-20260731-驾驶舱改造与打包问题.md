## 四、打包环境问题（⚠️ 当前阻塞项，务必先处理）

### 症状
- `electron-builder` 打包成功（exit 0，dmg/zip 都产出），但 `.app` **启动即退出、零输出、无日志**
- 直接跑 `Contents/MacOS/WeFlow`：无任何 stdout/stderr，进程 15 秒内消失

### 根因（已定位）
**`node_modules/electron/dist` 里的 Electron 实际是 v24.17.0，但 `dist/version` 文件写着 43.0.0**：
- `package.json` 声明 `electron: ^43.0.0` ✅
- `package-lock.json` 锁定 `43.0.0` ✅
- `node_modules/electron/package.json` = `43.0.0` ✅
- `node_modules/electron/dist/version` = `43.0.0`（假）
- `node_modules/electron/dist/Electron.app/Contents/MacOS/Electron --version` = **v24.17.0**（真，对应本机 Node 版本特征）

判断依据：
- 主二进制仅 33KB，`--help` 输出的是 **Node.js** 用法（`Usage: node [options]`）
- 真 Electron 主二进制 70-90MB；Electron 支持 `--versions`，该二进制报 `bad option`
- `v24.17.0` 是**系统 Node 版本**，不是 Electron 版本

即：`node_modules/electron/dist` 是一个**被 Node wrapper 混入/残留的旧 Electron 24**，`version` 文件被写成 43 掩盖了它。electron-builder 打包时把这个坏 dist 拷进 `.app`，产物跑不起来。

### 已执行的操作（截至 2026-07-31）
1. ❌ 首次打包失败：`dist-electron/main.js not found` —— 原因是直接跑 `electron-builder` 跳过 `vite build`，main.js 未生成。正确做法是 `npm run build`（内含 clean + tsc + vite build + electron-builder）。
2. ✅ `npm run build` 打包成功，但产物启动崩溃（根因如上）。
3. ⚠️ **已清空 `~/Library/Caches/electron/`**（原缓存含 `electron-v40.9.3-darwin-arm64.zip` + 两个 hash 目录）。
4. ⚠️ **已删除 `node_modules/electron/dist`**，跑 `node install.js` 重建，但下载超时中断（网络慢），**当前 dist 不存在**。

### 当前状态
```
node_modules/electron/dist  →  不存在（需重建）
~/Library/Caches/electron/  →  已清空
npm run dev / build          →  当前无法运行
```

### 修复步骤（接手者）
