设置页简化 · UI 设计稿

现状：11 个主 tab + AI 设置 5 个子 tab 一字排开，销售不该看到的全在眼前。方案：默认只给「常用」一页（外观 / 通知 / 安全 / 身份），其余 12 项收进「高级设置」二级页。原 tab 内容一行不改——这刀只收编导航，功能全部原样保留。

屏 1

日常 95% 的设置需求就这四件事：换主题、管通知、上锁、确认「我是谁」。每张卡内只保留最常用的控件，其余细节收进卡内「更多」或直接留原 tab。底部一个入口进高级设置。

改动对照清单（16 项设置的去向）

现有 tab处置去向 / 说明
外观常用主题三段控件进「常用」页；外观其余细节（字号等）留高级
通知常用总开关 + 白名单开关进「常用」；位置/名单维护等细节留高级「通知细节」
安全常用应用锁 + 自动锁定进「常用」；审计流水挪高级「数据」组（主管用）
身份档案（现位置各页分散）常用「我是谁」卡 = 当前身份 + 切换入口（点切换打开现有身份选择）
AI 设置 5 子页高级收进高级「AI」组一行，点进去原样
API 服务 / 模型管理高级「AI」组
数据库连接 / 缓存 / 自动下载高级「数据」组
防撤回 / 分析 / 关于高级「系统」组
铁律：所有原 tab 的内容组件一行不改，只动导航层。任何「顺手重写某个 tab」的行为打回。
