## 二、Action Funnel 口径契约（P0-4.2.2 定稿）

六段漏斗，**Task-level 去重**（每 task 布尔 0/1，不是 event-volume）：

| 段 | 定义 | 唯一事实来源 |
|---|---|---|
| ① created | 窗口内 follow_up_task（superseded 排除，另返回 supersededCount） | `follow_up_task` |
| ② exposed | **不可测**（G1 本期不做，N-A 不伪造分母） | `unmeasured` |
| ③ executed | task 至少一个执行事件（script_copied OR chat_opened OR follow_up_done，task_id 精确关联） | `customer_event` |
| ④ responded | task 产生后 session 有 customer_replied/quote_asked（session 轴关联——客户事件无 task_id） | `customer_event` |
| ⑤ progressed | task 产生后 `last_stage_change_at` 有变更 | `customer_profile.stage` |
| ⑥ won | `normalizeStage(stage) === 'won'` | `customer_profile.stage` |

口径守卫：任何分母 0 → rate = **null**（不返回 0%，防 UI 把「无样本」误读成「0% 转化」）；时序守卫（事件须 created_at >= task.created_at）；days 窗口只过滤 created，每 task 后续判定用全生命周期；无 task_id 执行事件不归入任何 task（不伪造关联）。
