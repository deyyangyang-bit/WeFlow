# PRD V1 · AI 销售助手（AI 原生销售 CRM）

> 版本：V1.0 ｜ 状态：方案定稿 ｜ 依据：项目现状差距分析（非从零设计）
> 定位：本地 AI 销售助手。AI 从微信聊天自动建立客户档案、识别商机、判断阶段，每天告诉销售"现在应该做什么"。不追求传统大而全 CRM。

## 产品理念

**聊天即录入，AI 即分析，CRM 自动生长，行动驱动销售。**

闭环：微信聊天 → 消息解析 → 客户识别 → AI 理解 → 客户画像 → 需求识别 → 商机识别 → 客户阶段 → 意向评分 → 风险识别 → 下一步行动 → AI 话术 → 销售执行 → 新的微信聊天 → 再次 AI 分析。

## 北极星指标

- **AI 自动发现的商机数**（每周新增）
- **今日行动卡片完成率**

销售不在乎字段数、报表数。核心是"让 CRM 消失在销售的工作流里"。

## V1 产品结构（6 个一级模块）

- **今日行动**（首页）
- **客户**
- **商机**
- **AI 分析**
- **销售知识**
- **系统设置**

## 自动化分级（V1 原则）

- **L0 纯自动**：消息解析 / 客户识别 / 标签 / 跟进记录 / 需求提取
- **L1 自动 + 可回滚**：客户阶段 / 意向评分 / 商机创建 / 客户画像 / 风险判断
- **L2 AI 建议 + 人工确认**：关闭商机 / 标记丢单 / 修改成交金额 / 修改预计成交日期
- **L3 必须人工**：发送微信 / 报价 / 承诺价格 / 合同 / 收款 / 成交

V1 不做 AI 自动发微信。

## P0（当前迭代）

### 1. 商机模块落地（opportunity 空表 → 完整闭环）
- AI 从聊天自动识别采购信号 → 自动创建商机（挂 account_id，stage 复用漏斗 5 档，amount 待确认）
- 一个客户多商机（不同产品线）
- 商机阶段 AI 推进，低置信进「信息待确认」队列（复用现有裁决体系，不新建）
- 商机漏斗（复用 SalesFunnelPage 的 ECharts 真漏斗，按商机 stage 分）

### 2. 意向评分 0-100
- 从 intent_tag_log 事件累计加权：主动询价 +15 / 确认数量 +15 / 谈价格 +10 / 竞品比较 -5 / 长期未回复 -8
- 点击分数 → 展开评分依据（复用 enrich 证据模式）

### 3. 风险预警结构化
- 四类风险：流失（报价后长期未回）/ 竞品（"XX 家比你低"）/ 价格（连续压价）/ 服务（"售后在哪"）
- 落到风险事件表 → 今日行动风险卡 + 客户详情风险区

## P1（后续迭代）

- 客户详情页升级：AI 画像证据链（每字段可点开看原话依据）+ 当前商机 + 需求 + 时间线
- 客户事件模型：intent_tag_log 泛化为事件流（询价/确认数量/谈价/催单/竞品介入），状态由事件计算
- 修复漏斗下钻 bug（比价 → 已报价空列表，映射对齐 negotiating）
- 自动化分级声明文档化

## P2（不做）

ERP / 财务 / 合同 / 发票 / 库存 / 提成 / OA / 审批 / 自动发微信 / 复杂团队权限 / 多平台销售渠道。

## 数据模型要点

- 不把 AI 结果覆盖式写 customer（现状已符合：状态由 intent_tag_log 事件 + customer_profile 计算）
- AI 输出结构化（enrich 已是 structured JSON，商机识别沿用）
- 商机表：`opportunity`（已建，补 CRUD + 事件表）
