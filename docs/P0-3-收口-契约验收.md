## ③ 最终架构（P0-3 CLOSED 后）

```
customer data ──► Canonical State / Evidence / Judgment（三真源）
                        │
                        ▼
              getCustomerCurrentView()   （只读组装层，唯一解释层）
                        │  IPC sales:customer:currentView
                        ▼
   360 判断卡  ·  SalesContextStrip  ·  今日行动卡   （三消费者，纯展示+行动）
                        ▲
                        │  suggest（用户主动，唯一 UI 触发生产路径，落库后重读闭环）
              generateActionAnalysis → customer_judgment
```

- **生产**（2 调用点）：预热 salesActionEngine（ai 24h 去重）+ suggest main.ts（manual 覆盖权利）
- **消费**（唯一入口）：`getCustomerCurrentView()` / `sales:customer:currentView`
- **历史保留**：`follow_up_task.analysis`（任务自身快照，不消费为判断）/ `insight_record`（历史见解记录，收件箱继续使用）
- **UI 铁则**：不现场调 LLM、不自拼判断、不把历史 JSON 当当前判断
