# 归档目录说明

> 本目录存放**历史资料**。当前文档入口见 `docs/CURRENT.md`。

## 铁律

1. **归档文档仅用于历史追溯**，默认**不得**作为当前需求、设计、排期或验收依据。
2. 只有**当前文档明确引用**的历史事实仍可被引用（例如 `AGENTS.md` 引用本文档中 `交接旧版/HANDOVER-20260731` §四 的 `ELECTRON_RUN_AS_NODE` 结论）。被引用的是那条事实，不是整份文档。
3. **新版生效后旧版进入归档**，不留在现行目录。
4. **同一主题在现行目录只保留一份权威版本**；需要并存时，必须在 `docs/CURRENT.md` 写明谁是权威。
5. 历史版本主要依靠 **Git 追溯**，不再在现行目录堆叠 `v1.6`／`最终版`／`最新版`／`HEAD版` 这类文件。
6. 文档进入归档时**必须记录替代文档**；没有替代文档的，明确写「无直接替代」。

## 默认读取规则

AI 与开发者**默认无需读取本目录**。仅当出现以下情形之一时才读取，并在读取时明确「这是历史资料」：

- 用户明确要求追溯历史；
- 现行文档明确引用了本目录中的某条事实；
- 排查回归需要核对当时的实现约定。
