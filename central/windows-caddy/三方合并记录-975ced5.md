## 5. 本轮补修（复核发现的四处问题）

| 问题 | 落地位置 | 关键行为 |
|---|---|---|
| **P1-1 记账写入失败后的进程回收** | `WeFlowNative.Common.ps1`（`New-WeFlowProcessIdentityRecord`、`Stop-WeFlowOwnedProcess`）、`Start-NativeCaddy.ps1`（`Invoke-WeFlowStartRollback`） | 启动后立即采集内存身份；回退优先用内存身份、磁盘记账仅兜底；身份不符/未知拒绝结束；结束后轮询确认退出；各步骤结构化结果 + `native-caddy.rollback.json`；结论只用布尔值 |
| **P1-2 含空格路径的真实参数传递** | `WeFlowNative.Common.ps1`（`ConvertTo-WeFlowWindowsArgument`、`ConvertTo-WeFlowWindowsArgumentLine`、`Start-WeFlowCaddyProcess`） | 按 MSVCRT/CommandLineToArgvW 规则构造单条命令行；空格/引号/结尾反斜杠正确；NUL/CR/LF 明确拒绝；`Start-Process` 不再接收数组 |
| **P2-3 启动验收统一契约** | `WeFlowNative.Common.ps1`（`Invoke-WeFlowEndpointAcceptance`、严格化的 `Test-WeFlowEndpointPayload`、`Get-WeFlowProbeExitCode`）、`Start-NativeCaddy.ps1`、`Test-NativeCaddyEndpoint.ps1` | `/health` 与 `/ready` 都必须 200 且契约成立；403 = 退出码 8 且触发回退；`ok` 必须是布尔、`protocolVersion` 必须是 JSON 整数；启动与诊断共用同一份判定 |
| **P2-4 Python 后端 HTTP 解析** | `WeFlowNative.HttpsProbe.py`、`WeFlowNative.HttpsProbe.Tests.py` | 用 `http.client` 解析（Content-Length + chunked + EOF 分帧），1 MiB 上限，截断/畸形/超限稳定失败；TLS 版本与密码套件在关闭连接前取得；只声明"链 + 主机名"验证范围 |

配套：`WeFlowNative.Tests.ps1` 新增 K/L/M/N/O 五组用例；`Test-DeploymentContract.ps1` 新增「本轮修复的不变量」静态断言；
`scripts/central-native-caddy-test.ts`（Mac 侧跨平台守卫）同步更新并通过。
